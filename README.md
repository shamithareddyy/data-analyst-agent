# Gemini-Powered Automated Data Insight Web Application

A full-stack web application that accepts Excel/CSV file uploads, performs automated data profiling and statistical analysis, generates interactive visualizations, and produces AI-driven business insights using the Gemini API.

---

## Project Structure

```
├── backend/          # FastAPI Python backend
├── frontend/         # React + Vite frontend
├── Plan.md           # Technical project plan
└── README.md         # This file
```

---

## Tech Stack

| Layer      | Technology                                      |
|------------|-------------------------------------------------|
| Frontend   | React 19, Vite, Tailwind CSS, Plotly.js, Axios  |
| Backend    | Python 3.12+, FastAPI, Pandas, NumPy, Plotly    |
| AI Layer   | Google Gemini API (generative insights)         |
| Animations | Framer Motion                                   |

---

## Features

- **File Upload** — Drag-and-drop or browse to upload `.csv` or `.xlsx` files
- **Data Profiling** — Automatic column type detection, missing value analysis, and descriptive statistics
- **Visualizations** — Auto-generated interactive charts via Plotly
- **AI Insights** — Structured business insights generated by Gemini API
- **Interactive Dashboard** — Unified view of stats, charts, and insights

## Getting Started

### Prerequisites

- Python 3.12+
- Node.js 18+
- A [Google Gemini API key](https://aistudio.google.com/app/apikey)

---

### Backend Setup

```bash
cd backend
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Install dependencies and run:

```bash
# Using uv (recommended)
uv sync
uv run uvicorn main:app --reload

# Or using pip
pip install -r requirements.txt
uvicorn main:app --reload
```

The API will be available at `http://localhost:8000`.  
Interactive docs: `http://localhost:8000/docs`

---

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.
